## สิ่งที่ต้องทำต่อก่อนถือว่าค้นครบ

1. รัน `node scripts/find-plant-images.mjs "Philodendron bipennifolium" --genus Philodendron`
   อีกครั้งตอน GBIF กลับมาทำงานปกติ แล้วตรวจภาพ iNaturalist ที่เหลืออีก 12 ภาพด้วยตา
   (เก็บไว้ที่ `docs/superpowers/image-candidates/philodendron-bipennifolium/` ซึ่งไม่ได้ commit
   เพราะอยู่ใน .gitignore — ต้องรันสคริปต์ใหม่ถ้าต้องการภาพเหล่านี้อีกครั้ง)
2. เข้าไปค้นในระบบของ tdc.thailis.or.th และ oatd.org โดยตรง (ไม่ใช่ผ่าน web search ทั่วไป)
   ด้วยคำค้นหลายแบบทั้งไทยและอังกฤษ ก่อนสรุปว่าไม่มีวิทยานิพนธ์ที่เกี่ยวข้อง
3. ค้นฟอรัมเฉพาะทาง (Aroid Forum, ฟอรัมนักปลูกไม้ด่างไทย) อย่างเป็นระบบแทนการเจอผ่าน ๆ
4. ลองอ่าน US5141866A ผ่าน Google Patents แทน USPTO PDF ที่อ่านไม่ได้ (ยังไม่ได้ลองรอบนี้)
