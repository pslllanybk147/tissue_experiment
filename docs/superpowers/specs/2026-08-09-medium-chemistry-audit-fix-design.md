# สูตรสารและตัวคำนวณเพาะเลี้ยงเนื้อเยื่อ — Design Spec

## เป้าหมาย

ทำให้สูตรสารและเครื่องคำนวณของระบบสอดคล้องกับอุปกรณ์จริงของผู้ใช้ และทำให้มือใหม่แยกได้ทันทีว่าอะไรเป็นสูตรตรงชนิด อะไรเป็นสูตรยืม และอะไรเป็นการทดลองเอง

## ขอบเขต

### รวมในรอบนี้

- แยกอัตราส่วนของ MS basal salts ออกจาก BCD/BCDAT อย่างชัดเจน
- ทำให้เครื่องคำนวณอาหารรับค่าฉลาก MS/BCD และความเข้มข้น stock ของ NAA, BA และ IBA จาก equipment profile
- ทำให้เครื่องคำนวณ Haiter ใช้ฐานฉลาก `w/w` ของผู้ใช้เป็นค่าเริ่มต้น และแสดงสมมติฐานความหนาแน่นที่ใช้แปลงเป็น `w/v`
- เพิ่มเครื่องคำนวณสารลดการเกิดสีน้ำตาลสำหรับ vitamin C, citric acid, PVP และ activated charcoal โดยแยกเป็นการทดลอง ไม่ปะปนกับสูตรอาหารหลัก
- เติมข้อมูลสูตร BCDAT ที่ทำตามได้ และแสดงคำเตือนว่าค่าที่ไม่มีงานตรงชนิดเป็นค่าทดลอง
- แสดงสูตรราก Thai Constellation และสถานะสูตรตั้งต้นของ Violin ให้ครบถ้วน
- เพิ่ม regression tests สำหรับทุก root cause ที่ตรวจพบ

### ไม่รวมในรอบนี้

- ไม่ยืนยัน protocol ใหม่สำหรับ Violin หรือพืชที่ไม่มีงานตรงชนิด
- ไม่เปลี่ยนค่าทดลองให้กลายเป็นค่าที่อ้างว่าเป็นงานวิจัยตรงชนิด
- ไม่เพิ่มสารเคมีใหม่เข้า inventory ของผู้ใช้โดยอัตโนมัติ
- ไม่สร้างขั้นตอนใช้สารปรอทหรือสารอันตรายที่ระบบไม่แนะนำ

## แบบจำลองข้อมูล

### Media ingredient

เพิ่มชนิดของฐานสารให้กับ ingredient ที่เป็นอัตราส่วน เช่น `MS` และ `BCD` แทนการตีความ `×` จากชื่อสารในตัวคำนวณ โดยสูตรจะเก็บอัตราฉลากของแต่ละฐานแยกกัน:

- MS ใช้ `msLabelRateGPerL`
- BCD ใช้ `bcdLabelRateGPerL` เมื่อเป็นผลิตภัณฑ์สำเร็จรูป
- BCDAT แบบผสมเองเก็บรายการเกลือเป็น `g/L`, `mg/L`, `mM` หรือ `µM` ที่ชัดเจน

ถ้ายังไม่มีอัตราฉลากที่จำเป็น ระบบต้องแสดง “ยังคำนวณไม่ได้” และไม่ใช้ค่า MS เป็นค่าแทน

### Stock solution

ขยาย `ToolLimits`/ข้อมูลที่ส่งเข้า calculator ให้มี:

- `naaStockMgPerMl`
- `baStockMgPerMl`
- `ibaStockMgPerMl`

ตัวคำนวณจะใช้ค่าจริงตามชื่อสาร หากสูตรมีฮอร์โมนที่ไม่ตรงกับ stock ที่ผู้ใช้บันทึกไว้ ต้องแสดงข้อผิดพลาดที่บอกชื่อสารและค่าที่ขาด

### หลักฐานของสูตร

ใช้ระดับหลักฐานที่มีอยู่ต่อไป และเพิ่มข้อความใน UI ให้เห็นได้ในบริบทของสูตร:

- `species-direct`: งานตรงชนิด/พันธุ์
- `adapted`: ยืมจากชนิดหรือสกุลอื่น
- `unsupported`: ค่าตั้งต้นหรือค่าที่ระบบยังไม่มีหลักฐาน

สูตร `adapted` และ `unsupported` ต้องมีป้าย “ทดลอง” ติดกับปริมาณ ไม่แสดงด้วยถ้อยคำเหมือน protocol ยืนยันแล้ว

## พฤติกรรมเครื่องคำนวณ

### อาหารเลี้ยง

- คำนวณน้ำตาลและวุ้นจากปริมาตรรวมเหมือนเดิม
- คำนวณ MS จากฉลาก MS เท่านั้น
- คำนวณ BCD จากฉลาก BCD เท่านั้น
- BCDAT ที่เป็นสูตรผสมเองจะแสดงรายการสารแต่ละตัว ไม่สร้างน้ำหนักจาก 4.43 g/L
- ฮอร์โมนใช้ stock concentration จาก profile และรายงานทั้ง mg ที่ต้องการกับ mL ที่ต้องเติม
- ถ้าปริมาตรต่ำกว่าความละเอียดของอุปกรณ์ ให้แนะนำ working dilution โดยใช้ concentration จริง ไม่ hard-code 1 mg/mL

### Haiter

- ค่าเริ่มต้นอ่านจาก profile เป็น 6% `w/w`
- แปลงเป็น `w/v` ด้วยค่าความหนาแน่นที่แสดงให้ผู้ใช้เห็น
- สูตร C1V1 = C2V2 ใช้หลังการแปลงเท่านั้น
- แสดงคำเตือนว่าความหนาแน่นเป็นค่าประมาณ หากไม่มีค่าจากฉลาก/การวัดของผลิตภัณฑ์

### สารลดการเกิดสีน้ำตาล

เพิ่มหน้าคำนวณ/บล็อกในคู่มือที่รับ:

- ปริมาตรสารละลาย
- ค่าต่ำ/ค่าสูงของสารแต่ละตัว
- หน่วย mg/L หรือ g/L
- สถานะ “สูตรทดลองจากพืชอื่น”

ค่าจากคู่มือเดิม เช่น ascorbic acid 20–100 mg/L, citric acid 10–100 mg/L, PVP 0.2–0.5 g/L และ charcoal 0.5–2 g/L จะไม่ถูกนำเสนอเป็นค่าที่เหมาะกับ Violin โดยอัตโนมัติ

## ข้อมูลสูตรที่จะปรับ

- Christmas moss และ Java moss: แสดง BCDAT แบบเต็ม/แหล่งอ้างอิง และไม่เรียกสูตร 10 g/L sucrose + 6 g/L agar ว่าเป็นสูตรตรงแหล่งเดิม
- Thai Constellation: แสดงรากด้วย activated charcoal 0.5 g/L + IBA 8 µM ในบริบทของขั้นราก
- Violin: ระบุสูตรตั้งต้นไม่ใส่ฮอร์โมนเป็น `unsupported experimental control`; BA 0.5 และ IBA 0.5 ยังคงเป็นค่าดัดแปลง
- Scindapsus: รักษาค่า inositol 100 mg/L และ thiamine HCl 0.4 mg/L แต่ระบุว่าอ้างจาก S. aureus และปิดการแสดงสูตรรากจนกว่าจะมีค่าครบ
- สูตรอื่นคงค่าปริมาณเดิมเมื่อคณิตศาสตร์ถูกต้อง แต่ปรับป้ายหลักฐานให้ตรงกับชนิดของแหล่งอ้างอิง

## การทดสอบ

เพิ่มหรือปรับ tests ให้ครอบคลุม:

1. BCD ไม่ใช้ MS rate เป็น fallback
2. BCDAT แบบผสมเองคืนรายการสารและหน่วยถูกต้อง
3. calculator ใช้ NAA/BA/IBA stock concentration จาก profile
4. stock ที่ไม่มีค่าหรือชื่อสารไม่ตรงแสดง error ที่ทำตามได้
5. Haiter profile 6% w/w แปลงเป็น 6.48% w/v ก่อนคำนวณ
6. recipe evidence แสดงป้ายทดลองสำหรับ `adapted` และ `unsupported`
7. สูตรลด browning คำนวณปริมาณตามหน่วยและแสดงคำเตือนแหล่งอ้างอิง
8. รัน test suite, lint และ production build หลังแก้

## ความปลอดภัย

- ห้ามนำกรดแอสคอร์บิกหรือกรดซิตริกไปผสมกับ Haiter/NaDCC ที่ยังล้างไม่หมด
- NaDCC และ Haiter ต้องแสดงฐานความเข้มข้นแยกจากกัน ไม่แปลงเงียบ ๆ
- สารปรอทยังคงสถานะ “ห้ามใช้ที่บ้าน” และไม่ถูกเพิ่มเข้าเส้นทางปฏิบัติ
- หากสูตรต้องใช้ H2O2, Mancozeb, silver nanoparticles หรือสารอื่นที่ไม่มีใน inventory ระบบต้องบอกว่าเส้นทางนั้นยังทำไม่ได้ด้วยชุดอุปกรณ์ปัจจุบัน

## ความสำเร็จที่ยอมรับได้

ผู้ใช้ที่มี profile ตามชุดอุปกรณ์จริงสามารถเลือกสูตร, เห็นฐานหน่วยที่ใช้, เห็นปริมาณ stock ที่ต้องเติม, และรู้จากหน้าเดียวว่าสูตรนั้นเป็น protocol ตรงชนิดหรือเป็นการทดลอง โดยไม่ต้องคำนวณเองหรือเดาความหมายของ “น้ำยาแม่”
