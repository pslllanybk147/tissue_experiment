# Cyber Greenhouse — Visual Redesign Design Spec

วันที่: 2026-08-07
สถานะ: รอผู้ใช้ตรวจ spec ก่อนทำ implementation plan

## เป้าหมาย

ยกระดับหน้าตาเว็บ Plantlover Lab ให้ "น่าใช้งาน" ตามทิศทางที่ผู้ใช้เลือกผ่าน mockup:

- อารมณ์: ป่าเขียวมีชีวิต + ล้ำสมัย (Full Cyberpunk HUD — อนุมัติจาก mockup `visual-style-v2.html` ตัวเลือก A)
- หน้าแรกจัดเต็มลูกเล่น / หน้าทำงานนิ่งอ่านง่าย (อนุมัติจาก mockup `work-pages.html`)
- สลับธีมมืด/สว่างได้ โหมดมืดเป็นค่าเริ่มต้น เคารพค่าเครื่อง (`prefers-color-scheme`) และจำค่าที่ผู้ใช้เลือก
- 3D hero เป็นภาพจำลองเขียนด้วยโค้ด (React Three Fiber) ไม่ใช่ภาพถ่าย/วิดีโอ

ขอบเขต: **เปลี่ยนเฉพาะชั้นผิว (visual layer)** — สี ฟอนต์ ขอบ เงา อนิเมชัน และ hero 3D บนหน้าแรก ห้ามแตะโครงสร้างข้อมูล, ตรรกะ Guided Runner, validator, เส้นทางหน้า (routes) และพฤติกรรมฟอร์มที่มีอยู่

## 1. หน้าแรก (`/`)

### Hero 3D

- คอมโพเนนต์ `HeroJar3D` ใช้ `three` + `@react-three/fiber` + `@react-three/drei`
- ฉาก: ขวดโหลแก้วใส (วัสดุโปร่งแสง มีการหักเห/สะท้อนแสง), ฝาโลหะเข้ม, ชั้นวุ้นอาหารเรืองแสงก้นขวด, ต้นอ่อน Philodendron แบบ stylized (ก้าน + ใบ 3–5 ใบ) ปักในวุ้น
- แสง: โทนนีออนฟ้า `#22d3ee` + เขียวมะนาว `#a3e635` ตามธีม; ค่าสีอ่านจาก CSS variables เพื่อให้เปลี่ยนตามธีมมืด/สว่าง
- การเคลื่อนไหว: หมุนรอบตัวเองช้า ๆ อัตโนมัติ; ผู้ใช้ลากด้วยเมาส์/นิ้วเพื่อหมุนได้รอบทิศ (OrbitControls จำกัดเฉพาะแกนหมุน ไม่ให้ zoom/pan จนหลุดเฟรม)
- โหลดแบบ lazy: หน้าแสดงภาพนิ่ง (static poster) ทันที แล้ว 3D เฟดเข้าแทนเมื่อโหลดเสร็จ
- Fallback: ถ้า WebGL ใช้ไม่ได้ หรือผู้ใช้ตั้ง `prefers-reduced-motion` → แสดงภาพนิ่งถาวร ไม่โหลด three.js เลย (dynamic import เฉพาะเมื่อจะใช้จริง)

### ลูกเล่น HUD รอบ hero (CSS/SVG ไม่ใช่ 3D)

- วงแหวนเส้นประ 2 วงหมุนสวนทางกันรอบโหล
- เส้นสแกนแนวนอนวิ่งผ่านโหลเป็นจังหวะ
- อนุภาคแสงลอยขึ้นช้า ๆ (จำนวนจำกัด ~10 จุด)
- ป้ายสถานะสไตล์ HUD (monospace, กะพริบเบา ๆ) — ถ้ามีข้อมูลรอบเพาะจริงของผู้ใช้ ให้แสดงรหัส/สถานะรอบล่าสุด; ถ้าไม่มี แสดงข้อความกลาง เช่น `READY`
- พื้นหลัง: กริดจาง ๆ + radial glow มุมจอ
- ทั้งหมดปิดเมื่อ `prefers-reduced-motion`

### ส่วนล่าง hero

- การ์ดทางลัด 3 ใบ: เริ่มเพาะ (`/start`), รอบของฉัน (`/my/rounds`), คู่มือ (`/find` หรือหน้า guide หลัก) — ขอบนีออนบาง, hover แล้วขอบสว่างขึ้น + ยกตัวเล็กน้อย
- เนื้อหา/ลิงก์เดิมของหน้าแรกที่มีอยู่ต้องยังเข้าถึงได้ครบ ไม่ตัดฟังก์ชันทิ้ง

## 2. ระบบสีและธีม

Design tokens เป็น CSS variables ใน `globals.css` สลับด้วย `data-theme` บน `<html>`:

| Token | มืด (ค่าเริ่มต้น) | สว่าง |
|---|---|---|
| พื้นหลังหลัก | `#070d1a` | `#f4f7fa` |
| พื้นการ์ด | `#0b1424` | `#ffffff` |
| ตัวหนังสือหลัก | `#f0fdff` | `#0f2436` |
| ตัวหนังสือรอง | `#9fb3c8` | `#46586a` |
| นีออนหลัก (ฟ้า) | `#22d3ee` | `#0891b2` |
| นีออนรอง (เขียวมะนาว) | `#a3e635` | `#4d7c0f` / ปุ่มหลัก `#3f6212` |
| เส้นขอบการ์ด | `rgba(34,211,238,.18)` | `#dbe5ee` |

- ปุ่มสลับธีมที่เมนูหลัก (desktop sidebar + mobile top bar) ไอคอนพระอาทิตย์/พระจันทร์
- ลำดับการเลือกธีม: ค่าที่ผู้ใช้เคยเลือก (localStorage) → `prefers-color-scheme` → มืด
- ห้าม flash ธีมผิดตอนโหลดหน้า (ตั้ง `data-theme` ก่อน paint ด้วย inline script)
- ทุกคู่สีข้อความ/พื้นหลังต้องผ่าน contrast ตามที่ ui:verify ตรวจอยู่เดิม

## 3. หน้าทำงานทั้งหมด (guide, my/rounds, start, find, search, problem, substances, form, admin)

ตาม mockup `work-pages.html` ที่อนุมัติ:

- ไม่มีอนิเมชันต่อเนื่องขนาดใหญ่ ยกเว้นจุดเดียว: ไฟสถานะ `SESSION ACTIVE` กะพริบเบา ๆ (ปิดเมื่อ reduced motion)
- การ์ดเนื้อหา: ขอบบาง + เส้นเน้นซ้าย 3px สีนีออนหลัก
- แถบความคืบหน้า: ไล่สีฟ้า→เขียวมะนาว มี glow ในโหมดมืด
- ป้ายสถานะ (chip): monospace ขอบสีตามความหมายเดิม (Verified/Adapted/Experimental/Pending review ยังใช้ระบบ evidence เดิม เปลี่ยนเฉพาะหน้าตา)
- ปุ่มหลัก: โหมดมืด = ขอบนีออนเขียวมะนาว, โหมดสว่าง = พื้นทึบเขียวขี้ม้าตัวหนังสือขาว
- โครงหน้า, ลำดับเนื้อหา, ข้อความ, focus behavior (`focusStepTop()`), touch target — คงเดิมทั้งหมด

## 4. ฟอนต์

- เนื้อหาไทย/หัวข้อ: **IBM Plex Sans Thai** (ผ่าน `next/font` แบบ self-host, มี fallback เป็น Noto Sans Thai / system font)
- ตัวเลข ป้าย HUD และข้อความสถานะ: **IBM Plex Mono** (หรือ Geist Mono ที่มีอยู่แล้ว ถ้าลดจำนวนฟอนต์ได้ให้ใช้ของเดิม)
- ห้ามโหลดฟอนต์จาก CDN ตอน runtime

## 5. ประสิทธิภาพและการเข้าถึง

- three.js + ฉาก 3D โหลดเฉพาะหน้าแรก ผ่าน dynamic import; หน้าอื่นห้ามมี three ใน bundle
- งบน้ำหนักหน้าแรก: JS เพิ่มจากเดิมได้ไม่เกิน ~150KB gzip สำหรับชุด 3D (โหลดหลัง first paint)
- `prefers-reduced-motion`: ปิดอนิเมชันทุกชนิดรวม 3D auto-rotate (เหลือภาพนิ่ง) — ต้องผ่านการตรวจ reduced motion เดิมใน ui:verify
- ผ่านเกณฑ์เดิมทั้งหมด: `npm test`, `npm run lint`, `npm run build`, `npm run firebase:verify`, `npm run ui:verify` (14 ความกว้าง 360–1920px, keyboard, Thai overflow, touch target, contrast)
- เพิ่มการตรวจใหม่ใน ui:verify: สลับธีมแล้ว contrast ผ่านทั้งสองโหมด, หน้าแรกมี fallback ภาพนิ่งเมื่อปิด WebGL/reduced motion

## 6. สิ่งที่ไม่ทำ (out of scope)

- ไม่ใช้วิดีโอพื้นหลัง / ไม่ใช้ Spline หรือบริการ 3D ภายนอก
- ไม่แตะ schema ข้อมูล, Firestore rules, ตรรกะ validator, เส้นทางหน้า
- ไม่ทำ 3D ในหน้าอื่นนอกจากหน้าแรก
- ไม่เปลี่ยนข้อความ/เนื้อหาคู่มือ
